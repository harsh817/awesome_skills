# Editing Style Director

Use this skill when a video needs a specific edit language, a reference-style breakdown, or a reusable editing style that can change independently from the creative strategy.

## Role

Own the edit grammar, not the marketing strategy. The creative director decides what the video must achieve; this skill decides how the edit should feel and move.

## Style Pass

Define the editing style in production terms:

- Cut rhythm: fast cuts, slow holds, punch-ins, freezes, or beat-matched transitions.
- Shot grammar: clone comparison, split screen, talking head, product insert, screen capture, model demo, before/after, montage, or proof board.
- Typography: caption density, title scale, emphasis words, lower thirds, labels, and readability.
- Overlays: arrows, pointer lines, boxes, heat maps, red X marks, circles, zoom windows, detail cards, or annotations.
- Motion: zooms, slides, parallax, wipes, pop-ins, tracking callouts, or still-image camera moves.
- Visual proof devices: comparisons, diagnosis marks, detail inserts, checklists, timelines, or transformation reveals.
- Audio relationship: narration-led, beat-led, sound-effect accents, or music-led pacing.

## Style Pack Routing

Use [references/style-pack-structure.md](references/style-pack-structure.md) when creating or updating reusable editing styles.

Future editing styles should live as references in this skill, not inside the creative director. Name them by edit language, not by project name, for example:

- `studio-diagnosis-fashion.md`
- `ugc-founder-confession.md`
- `premium-product-demo.md`
- `meme-reaction-breakdown.md`
- `documentary-proof-thread.md`
- `kinetic-typography-educator.md`

When a user provides a reference video, create or select a style pack from the reference. Borrow the edit grammar, not the exact shots.

## Handoff

Return a style brief for the storyboard and editor:

- Chosen style pack or style name.
- Timing rules and cut rhythm.
- Overlay system.
- Typography system.
- Required proof devices.
- Transition and motion rules.
- What must not be used because it would break the style.
